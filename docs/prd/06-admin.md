## 6.2 一、课堂管理

### 课堂分类
- 一级/二级分类
- 排序（拖拽）
- 上下架

### 课堂编辑
| 字段 | 说明 |
|------|------|
| 主图 | 尺寸按参考网站 |
| 标题 | 主标题 |
| 副标题 | 副标题 |
| 商品价格 - 普通价格 | 金币数 |
| 商品价格 - 会员价格 | VIP免费，前端显示0 |
| 商品详情 - 主标题 | - |
| 商品详情 - 副标题 | - |
| 商品详情 - 详情图 | 多张 |
| 分类 | 一级/二级 |
| 标签 | 多选 |
| 质量标注 | 下拉 |
| 资源 | 网盘链接+提取码（可多个） |
| 状态 | 发布/草稿/上下架 |

| 支付方式开关 | 启用/禁用 |
| 手续费查看 | 各渠道费率 |
| 对账配置 | 自动对账设置 |

### 充值记录管理
- 普通充值记录
- 会员充值记录

## 6.8 评论管理

### 功能
- 用户评论回复
- 删除违规评论
