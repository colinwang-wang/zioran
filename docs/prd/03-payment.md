# 03 - 付费模块

## 3.1 金币系统

### 概念
- 站内虚拟货币："金币"
- 用于购买课程和 VIP
- 不可提现、不可转让
- 通过微信/支付宝充值获得

|------|------|------|
| ¥10 | 10 | - |
| ¥50 | 50 | - |

### 购买 VIP 流程
1. 点击"立即升级" → 检查登录状态
2. 未登录 → 弹出登录弹窗
3. 已登录 → 检查金币余额
4. 余额不足 → 提示充值
5. 余额充足 → 确认弹窗 → 扣金币 → 开通 VIP
6. 成功 → 跳转个人中心

## 3.3 支付管理（后台）

### 订单管理
- 全部订单列表
- 字段：订单号、用户、商品、实付金额、支付状态、下单时间
- 支持按时间筛选

### 支付配置
| 配置项 | 说明 |
|--------|------|
| 微信支付 | 商户密钥配置 |
| 支付宝 | 商户密钥配置 |
| 回调地址配置 | 支付成功回调 |
| 支付方式开关 | 启用/禁用微信或支付宝 |
| 手续费查看 | 各渠道手续费展示 |
| 对账配置 | 支付对账设置 |

### 充值记录管理
| 类型 | 说明 |
|------|------|
| 普通充值 | 用户自主充值记录 |
| 会员充值 | VIP购买记录 |
