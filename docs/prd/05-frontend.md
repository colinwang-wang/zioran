# 05 - 前端实现要点

## 全局组件

### Header
```
┌──────────────────────────────────────────────────┐
│ [Logo] 知猿   首页  知猿课堂  留言反馈  成为会员   │
│                           [图标] VIP  🔍  登录    │
└──────────────────────────────────────────────────┘
```

**Left（左侧导航）：**
- 首页 → `/`
- 知猿课堂 → `/courses`（hover展开分类下拉）
- 留言反馈 → `/guestbook`
- 成为会员 → `/vip`
- 图标

**Right（右侧）：**
- VIP 图标
- 搜索图标 → 点击展开搜索弹层
- 登录 → `/login`
- 登录后显示：个人中心（头像+下拉菜单）

### 搜索弹层
- 点击搜索图标 → 展开搜索弹层
- 输入关键字回车 → 跳转搜索结果
- 实现站内搜索

## 首页模块

### 金刚区
```
┌────────────────────────────────────────────────┐
│  [AIGC课堂]  [Blender课堂]  [...]              │
│                                                │
│  主副标题后台都可以添加                          │
│  如果后期在后台有新增导航模块，                   │
│  链接到的内容模块也一样就行，                    │
│  只是内容后台可以调整，模块框架不用变             │
└────────────────────────────────────────────────┘
```
- 与后台分类对应
- 点击进入对应分类页面

### Banner
- 广告页（后台可更换，静态或者动态页面）

### 搜索区
```
搜索上面的主文案：知猿课堂，学有所长
搜索上面的副文案：以知为基，以猿为伴，打造优质网课资源课堂
[________ 搜索一下 ________]
```

### 最新发布
- 按发布时间显示8个商品（上四下四布局）
- "查看更多" → 最新发布的全部课堂页面（`/new`）

### 知猿课堂
- 二级导航：全部课堂 / AIGC课堂 / Blender课堂 / ...
- 二级导航可根据后台管理
- 各分类按发布时间显示8个商品（上四下四布局）
- 查看更多：
  - 全部课堂 → `/courses`
  - AIGC课堂 → `/courses/category/aigc`
  - Blender课堂 → `/courses/category/blender`

### 关于VIP
- 文案和样式参考网站（原价699金币）

## 响应式断点

| 断点 | 宽度 | 课程卡片列数 |
|------|------|-------------|
| Desktop | ≥1024px | 4 列 |
| Tablet | 768-1023px | 3 列 |
| Mobile | <768px | 2 列 |
