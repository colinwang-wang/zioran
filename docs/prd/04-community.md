# 04 - 留言反馈与评论

> PDF需求明确：移除问答社区和投稿系统，保留留言反馈功能。

## 4.1 留言反馈

### 路由
`/guestbook`（Header导航：留言反馈）

### 页面结构
```
┌─────────────────────────────────────────────────┐
│  留言反馈                                         │
│  需要其他课程可以留言，说明：【机翻的课程不要留言】   │
│                                                  │
│  留言 234                                         │
│                                                  │
│  ┌─────────────────────────────────────────────┐ │
│  │ [输入留言内容...]                             │ │
│  │ [提交留言]                                   │ │
│  └─────────────────────────────────────────────┘ │
│  （未登录时显示"请先登录后留言"）                   │
│                                                  │
│  ┌─────────────────────────────────────────────┐ │
│  │ 👤 makoto                         👍 21      │ │
│  │ 求恶童在养猫的硬边缘场景色彩专项训练营         │ │
│  │ 2025-03-19                                   │ │
│  ├─────────────────────────────────────────────┤ │
│  │ 👤 yc001                          👍 14      │ │
│  │ 求tx科学 49天日训企划...                      │ │
│  │ 2025-03-22                                   │ │
│  ├─────────────────────────────────────────────┤ │
│  │ ...                                          │ │
│  └─────────────────────────────────────────────┘ │
│                                                  │
│  <  1  2  3  ...  >                              │
└─────────────────────────────────────────────────┘
```

### 交互
- 登录后可发表留言
- 点击 👍 可点赞/取消（需登录）
- 自己的留言可删除
- 管理员可隐藏/置顶

### API
```
GET    /api/v1/guestbook?page=1&pageSize=10
POST   /api/v1/guestbook
       Body: { "content": "string" }
POST   /api/v1/guestbook/:id/like
DELETE /api/v1/guestbook/:id
```

## 4.2 评论系统

### 位置
课程详情页底部

### 页面结构
```
│  评论 N                                          │
│                                                  │
│  ┌─────────────────────────────────────────────┐ │
│  │ [输入评论内容...]                             │ │
│  │ [发表评论]                                   │ │
│  └─────────────────────────────────────────────┘ │
│  （未登录显示"请先登录后评论"）                     │
│                                                  │
│  👤 用户A                          2026-06-01    │
│  这个课程讲得很好，推荐！                          │
│                                                  │
│  👤 用户B                          2026-06-02    │
│  课件很全，感谢分享                               │
│    ↳ 管理员回复: 感谢支持                         │
```

### 交互
- 需登录才能评论
- 管理员可回复评论
- 支持嵌套回复

### API
```
GET    /api/v1/comments?targetType=course&targetId=xxx&page=1&pageSize=10
POST   /api/v1/comments
       Body: { "targetType": "course", "targetId": 1, "content": "string", "parentId": null }
DELETE /api/v1/comments/:id
```
