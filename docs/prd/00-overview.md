# 00 - 总览与架构

## 项目定位

网课资源付费下载站。
新站名称：**知猿**，域名：**zioran.com**。
Slogan：**知猿课堂，学有所长**
副文案：以知为基，以猿为伴，打造优质网课资源课堂

## 新站技术选型（前后端分离）

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | Next.js 14 (App Router) | SSR/SSG，SEO 友好 |
| UI | Tailwind CSS + shadcn/ui | - |
| 后端 | Go (Gin) | RESTful API |
| 数据库 | MySQL 8 | 主库 |
| 缓存 | Redis | Session、热点数据、验证码 |
| 文件存储 | 阿里云 OSS | 课程封面/预览图/资源 |
| 图片处理 | OSS 图片处理 | 缩略图裁剪 |
| 搜索 | PostgreSQL 全文搜索 | 初期够用，后期可换 Meilisearch |
| 支付 | 微信支付 + 支付宝 | - |
| 部署 | Docker Compose | Nginx + Go + Next.js + PostgreSQL + Redis |

## 页面层级结构

```

├── header.header                    # 顶部导航
│   └── .container
│       ├── .logo                    # Logo（知猿）

```
