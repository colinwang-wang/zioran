## 9. 复刻开发建议

### 方案 A：WordPress 复刻
- 安装 WordPress + Modown 主题 + erphpdown 插件
- 优点：功能完全一致，零开发
- 缺点：PHP 技术栈，定制受限

### 方案 B：现代技术栈复刻
推荐技术选型：
- **前端**：Next.js / Nuxt（SSR/SSG，SEO 友好）
- **后端**：Node.js (Nest.js) / Go / Python (FastAPI)
- **数据库**：PostgreSQL
- **文件存储**：S3/OSS/COS
- **支付**：微信支付 / 支付宝
- **搜索**：Elasticsearch / Meilisearch

需要实现的核心模块：
1. 用户系统（注册/登录/JWT/验证码）
2. 课程管理（CRUD/分类/标签/质量标注）
3. 付费系统（VIP 会员/单课购买/金币）
4. 文件下载（购买后可见/防盗链）
5. 留言板
6. 问答社区
7. 投稿审核
8. 搜索
9. 评论系统
10. 点赞/社交分享
