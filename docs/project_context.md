## 项目定位

在线课程资源站，参考大元资源网（chenwenb.com）复刻开发。

## 核心功能

- 课程分类浏览（14个分类：3dmax、AE、AIGC、Blender、C4D、UI、zbrush、室内设计、平面设计、手绘、摄影、电商设计、视频课程等）
- VIP 会员 + 单课购买付费体系
- 留言板 / 问答社区 / 投稿
- 用户系统（注册/登录/金币）
